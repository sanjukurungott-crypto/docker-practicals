# Docker Lab Practicals Submission

This repository contains submissions for the 4 Docker lab experiments:

1. **Layer Optimization (`optimizedapp`)**: Demonstration of multi-stage and cached Dockerfile builds.
2. **Copy-on-Write (`cow-demo`)**: Demonstrating file modification in container storage layers.
3. **Secrets Management (`manage-secrets-demo`)**: Securely managing sensitive data using Docker Compose secrets.
4. **Persistent Storage (`persistent-storage-demo`)**: Configuring and verifying Docker volumes and persistent data mounts.
